# 主升浪前兆评分器 V2 设计

## 目标

在 V1 候选池的数据加载、风险过滤、板块聚合和页面路由上增量升级评分逻辑，使排名更关注接近新高、均线结构和放量迹象，而不是单纯偏好低波动趋势股。

## 评分模块

新增 `factors/main_wave_scores.py`，提供 `calculate_main_wave_scores(df)`。该函数只处理选股截面，不下载数据，也不修改输入。

- 趋势结构：`Close > ma20`、`Close > ma60`、`ma20 > ma60` 各占三分之一，缺失比较按 0。
- 新高接近度：20/60 日接近度分别按截面百分位排名后等权。
- 量价突破：5/20 日量比、20/60 日量比、上涨/下跌日量比按 0.40/0.30/0.30 加权。
- 风险分：按 20 日波动率四档映射到 1.0/0.8/0.5/0.2，缺失为 0。
- 风险惩罚：`0.05 * (1 - risk_score)`。

截面排名字段部分缺失时使用该列中位数；整列缺失时得分为 0，确保单个异常字段不会中断全池。

## V2 总分

`main_wave_score` 按用户指定权重组合 20/60 日动量、新高、趋势结构、量价突破、板块强度和小权重风险分。`raw_score` 等于 `main_wave_score`，`final_score` 为扣除风险惩罚后向下截断到 0。

## 接入

`selection/main_wave_selector.py` 保留下载、过滤和排序职责，只调用新评分函数，并扩展标准输出列。`app.py` 仅修改主升浪页面说明，原单股回测路径不变。策略文档更新为 V2 公式。

## 验证

单元测试覆盖所有新增分数、波动率档位、缺失值回退和最终扣分；现有选择器与 Streamlit AppTest 验证新增列、默认股票池、CSV 和单股页面无回归。
